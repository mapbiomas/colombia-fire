# 🔥 MapBiomas Fire Colombia

This repository contains the scripts for mapping burned areas in Colombia as part of the **MapBiomas Fire** initiative.

The scripts support the processing, classification, and analysis of satellite imagery used to identify and map burned areas across the Colombian territory.

The workflow is based on the method developed and implemented by **MapBiomas Fuego Brasil** (IPAM), adapted to the Colombian territory.

For detailed information about the methodology, classification criteria, and processing workflow, refer to the official [MapBiomas Fire methodology](https://brasil.mapbiomas.org/metodo-mapbiomas-fogo/).

## 🚀 Prerequisites

- A **Google Earth Engine** account ([sign up here](https://earthengine.google.com/)).
- Basic familiarity with the Google Earth Engine Code Editor.

## 📂 Repository Modules

### 1. [Fire Landsat 30m (`fire_landsat_30m/`)](./fire_landsat_30m/README.md)

Workflows, notebooks, and methodological configurations for burned-area classification using 30-meter Landsat imagery. This module contains the procedures and parameters used for `collection_01` across the ecoregions of Colombia.
